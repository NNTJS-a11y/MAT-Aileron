# MAT Aileron | Steer Your Laboratory

MATLAB 内运行的独立助手窗口，支持兼容 Chat Completions 的服务、流式多轮对话、文档附件、代码预览、方法摘要与基础 Simulink 建模。不是 MathWorks 官方产品。当前实机验证环境为 R2024a。

## 安装与更新

完整解压统一便携 ZIP，运行 Install-Windows.cmd，手动选择已有且授权的 MATLAB。也可在 MATLAB 中进入程序目录运行 setupMatlabAI。安装后在MATLAB命令窗口输入 `Aileron` 唤起助手，普通MATLAB图标不自动打开助手。Start-Windows.cmd是主动启动助手的可选入口；uninstallMatlabAI 移除命令路径注册块，保留个人 startup.m 其他内容。安装会备份已有启动脚本。

程序文件夹需长期保留，移动后重新运行安装入口。更新后保存工作并重启 MATLAB。程序目录不再用于保存运行结果；首次安装和命令路径注册配置仍需有相应目录写权限。同一 ZIP 不需要挑选分版本适配文件。

## API 与隐私

右上角“API设置”配置完整 API 地址、服务商模型名称及该服务的 API Key。地址和模型保存在当前电脑的 MATLAB preferences；密钥仅保留在窗口内存，也可读取 MATLAB_AI_API_KEY、DEEPSEEK_API_KEY 或 OPENAI_API_KEY 环境变量。取消设置撤销修改。ChatGPT 订阅与第三方 API 由各服务单独提供。

发送会将当前需求、保留的上下文、附件提取文字和主动勾选的编辑器脚本发给配置的服务。不要把密钥写进代码或打包文件。界面的密钥字段不会写入恢复记录；用户主动在聊天中输入的文字会随对话保存。模型服务可能依据自己的政策保留请求。

## 多轮上下文与长回复

每个请求只在最新输入中放一份当前附件、当前代码/JSON及最近本地反馈。历史只保留指令与精简回复，不重复嵌入旧代码和附件。更换或移除附件后，旧附件全文不会从历史再次上传；旧回复中的结论仍可能提及它，彻底重置用“新对话”。

“工作区 → 工作区设置”可设置上下文预算，默认128,000，采用 UTF-8 字节数加协议余量作保守 token 估计，不是模型精确 tokenizer，也不自动识别服务限制。预算不足时先移除最早的完整问答并提示；最新需求、附件、系统要求与当前代码不会静默截断，仍超过预算时明确拒绝发送。另保留800,000字符的本地总量上限。服务实际限制可能更低，预算应留出输出空间。

网络采用原生 SSE，支持停止生成；连接15秒、首响应90秒、空闲60秒，总监控约600秒。协议总量32MB、正文500,000字符。不完整或服务标记截断的内容不作为有效代码或方案。长正文刷新间隔约0.5秒（短回复可即时显示），流式预览只显示末尾24,000字符。对话窗口最多显示末尾60,000字符，完整记录可从工作区菜单导出。完整代码仍在代码预览中；很长的代码编辑仍可能耗费渲染时间。

## 代码运行与数学检查

生成后自动做本机公开 codeIssues 静态检查；手动修改后可“检查代码”。error 级问题阻止运行，普通提示不阻止。“分析结果 / 修复”发送当前代码和实际诊断，修复不自动执行。局部函数通过独立 .m 文件处理，不直接在命令行 eval 函数定义。

“运行代码…”经确认后，使用同一套 MATLAB 的独立进程和空工作区执行。主工作区变量不自动传入，结果不自动回灌。默认总超时300秒（含进程启动、许可等待），可在工作区设置为10～3600秒；运行期间“停止生成”变为“停止运行”，终止计算进程。需要系统允许启动另一 MATLAB 进程及可用许可，失败不会回退到主工作区执行。

源 .m、process.log、状态文件保留；脚本工作区尽可能保存到 workspace.mat，图形尽可能导出为 PNG 和 FIG。主函数内的局部变量遵循函数作用域，不会自动出现在基础工作区快照中；无法序列化的数据或特殊图形可能无法保存。计算进程图窗默认隐藏；完成后主 MATLAB 会打开持久PNG图像窗口，直到用户手动关闭。可从工作区菜单再次查看最近运行图像；原始FIG保存在运行目录供用户自行打开。自动图像窗口是栅格查看，不承诺保留曲线编辑能力。带固定输入参数的主函数保存后需手动提供参数调用；任意多文件工程与 classdef 不由单文件运行入口处理。

**进程隔离不是磁盘安全沙箱**。生成代码仍按当前用户权限读写文件，停止不回滚已写出的内容。运行前检查输入路径、文件操作及所需工具箱。附件原路径没有传给模型，代码应显式定义数据或用文件选择器选择原文件。独立运行不能直接复用主工作区变量。

静态检查不验证数学结论。生成提示要求检查单位、维度、缺失值、约束、残差/基准与数据来源；“模型与算法说明”供人工核对，不能代替数值实验或专业审阅。方法摘要来自同一回复，不读取服务商内部 reasoning_content，也不额外发起 API 请求。

## 附件与质量提示

支持 DOCX 正文与表格、文字 PDF、XLSX/XLS/XLSM 多工作表及 TXT/M/MD/CSV/TSV/JSON。旧 DOC 另存 DOCX；扫描 PDF 与图片需先 OCR。PDF 公式、图片和排版可能未提取，添加后请预览。Excel 只读取已有值，不执行宏、不重算公式，公式缓存可能过期。

最多10份、10MB/份、40,000字符/份、合计80,000字符。PDF 最多200页；现代工作簿解压最多25MB。Excel 预检每张工作表的范围与实际单元格地址，再使用显式范围读取：最多5000行、100列、50,000格，包含格式单元格。异常或无坐标的单元格明确拒绝，避免截取部分表格冒充完整输入。现代工作簿通过关系表匹配工作表，不依赖 ZIP 条目顺序。旧 XLS 使用 OLE/BIFF 元数据预检，不需额外 JAR；不支持的旧格式或加密文件需另存 XLSX。

勾选附件行前方框后“移除所选”；勾选只用于移除，发送包含列表中全部保留附件。点击文件名用于预览。移除/清空不删除磁盘原文件。批量导入中途失败不加入该批次；相同名称与相同文字不重复添加。附件读取仍在主线程，预检限制降低风险但不承诺任意损坏文件都能瞬时返回。

## 用户数据与会话恢复

“工作区 → 工作区设置”可选择结果及会话目录；默认位于 prefdir 下 MAT-Aileron。runs 保存独立执行材料，models 保存 Simulink 文件，checks 保存静态检查副本，sessions/latest.json 保存恢复记录。不会把数据写进便携包，换电脑复制程序也不会复制聊天或密钥；如需迁移记录，单独管理数据目录。

实际使用默认启用本地保存：保存已提交的编辑、请求结束后的对话、附件与代码；正常关闭前再次保存。JSON 恢复记录不含设置中的密钥，不会执行恢复的代码，自动仿真恢复时关闭。可在设置中关闭保存并删除当前目录恢复文件。启动默认进入新任务；需要接续时在工作区菜单明确选择“恢复上次会话”。未执行草稿或尚未归档的旧会话会保存为历史快照，不自动成为当前指令。“新对话”以空会话替换恢复记录，不删除已有运行结果。

草稿在编辑提交/失焦及正常关闭时保存；强制结束进程可能丢失未提交的最后输入。恢复记录上限12MB，超过或磁盘写入失败时底部显示保存错误。损坏记录不会自动执行，先保留文件供排查。切换数据目录保留原文件，旧目录的记录需自行清理。多个助手进程共享同一数据目录时当前恢复文件由最后保存者覆盖，建议设置不同数据目录。

“清理检查缓存”先显示数量并确认，只删除已验证目录内的检查 .m 副本，不递归跟随子目录；不删除运行结果。运行结果长期保留，应定期在所选目录手动归档或清理。

## Simulink 与版本

PID 示例免 API，可真实创建并仿真。AI 模式支持 Step、Constant、Sine、Sum、Gain、TransferFcn、Integrator、PID、Saturation、Scope，最多40模块与100连接。方案结构、端口、数值参数及模块兼容性检查后创建唯一新模型，不覆盖原模型。自动建模可关闭。

本机仿真仍在当前 MATLAB 中进行，有60秒计算超时；“停止运行”用于独立普通代码，不等于停止 Simulink 仿真。模型、JSON、MAT、CSV与PNG保存在用户 models 目录。“读取当前模型”只读取顶层结构；反馈只含摘要与最多80点样本，不能据此声称精确峰值和调节时间。

目标下拉为 R2023a～R2026b 的生成兼容目标，不切换已安装软件、不认证所有版本。选择与当前版本不同仍可生成代码/方案，本地 Simulink 建模要求目标等于实际版本。兼容自检检查当前环境的代码分析、UI、流式 HTTP、PDF、XLS及数据目录写入能力；实时脚本内部接口不可用时回退普通脚本。R2024a 外版本待实机验证，旧格式导出后在 R2024a 重开不代表旧版本实测。

## 验证

运行 tests/runFullValidation：24组本机回归，含真实 Simulink、原生本地 HTTP、会话/上下文、Excel 预检，以及真实独立 MATLAB 执行、死循环取消和超时；不调用付费 API。tests/testWaitingAnimation.js 检查静止曲面、移动光带、停止与减少动态效果；tests/testLauncher.ps1 检查启动参数及路径转义。测试文件、日志、运行结果与会话不随干净 ZIP 分发。

当前等待动画仍是中央静止膜面与移动光带。之前的粒子爱心是独立演示，没有加入助手或安装包。

## 可搜索历史与跨任务接续（2026-11-01）

左侧“历史任务”保存每次完成的问答及当时的代码、方法说明、附件文字和本地反馈。输入关键词后回车或失焦，按问题与回复摘要筛选。选择记录可预览，按“引用所选”才会应用到下次提问；不会替换当前代码或自动执行。Ctrl多选最多3条，底部显示当前引用，可随时清除。历史引用仅用于下一次实际发送，开始请求后即清除（包括网络失败与取消）。历史附件默认不带，只有勾选“本轮附带历史附件”才携带，重复文字去重。

历史条目记录引用关系：默认只引用所选记录，只有勾选“本轮追溯上游步骤”才会追溯，最多8条去重依赖，超出或依赖被删除时明确提示；预算超限不会静默截断。用户当前要求优先，旧版本、数据、假设冲突应核对。历史不能代替多文件工程依赖管理。

“新任务/新对话”清除当前代码、问答、附件、反馈、旧编辑器脚本发送选项和引用，保留历史；“删除历史”需确认，不删除原附件或运行文件。工作区菜单可收起侧栏或保存当前任务快照。旧版仅保存的最近会话可迁移为一条历史，以前未保存的已关闭对话无法补回。

启用本地保存时，历史保存在用户数据目录 history/，index.json为检索元数据，每条记录单独JSON，最多2000条、每条12MB。记录可能包含附件和源代码，界面设置中的密钥不保存。关闭本地保存会删除当前数据目录的历史和会话记录，旧数据目录仍需自行清理；仅在内存中的本次记录仍可使用，关闭后消失。换电脑复制程序不携带历史。多个实例同时写同一目录仍可能发生最后写入覆盖，建议使用不同数据目录。

## 拟合、图像保留与上下文隔离修复

运行前增加已知API误用检查：vander只接受一个输入向量，不支持vander(x,p)。三次多项式拟合建议polyfit(x(:),y(:),3)，或者构造A=x(:).^(p:-1:0)再最小二乘。检测不自动改写数学模型；现有错误代码可点击分析结果/修复后重检。该检查不是所有运行时错误的静态证明，函数、数据维度、工具箱与算法仍可能出错。

图像由运行进程导出，在主MATLAB持久显示至手动关闭；新任务、历史检索和计算进程退出不会关闭这些图片。“工作区→查看最近运行图像”可重新打开。PNG为实际输出快照；FIG文件留在运行目录，不自动在主进程加载其中回调。特殊图形无法导出时会记录到process.log，不掩盖计算结果。

历史搜索和列表选中只用于定位。引用属于单轮显式选择，不随下一轮、恢复或重新启动自动携带；只有启用对应勾选项才带历史附件或上游记录。当前指令位于独立current_task区，排在历史参考之后；历史中的旧保存位置、旧执行命令不得自动继承。同一任务继续追问仍会保留该任务自己的上下文，切换问题请点新任务。

## 功能精简：移除结果验证

已移除独立的“结果验证”页签、验证按钮、JSON规则以及后台数值证据采集。普通运行不再生成evidence.json，也不因此阻止结果保存。已有运行文件、历史记录和旧证据文件保留，不自动删除用户数据。旧恢复记录中的验证字段会被忽略。

运行前语法和已知接口误用检查、运行报错反馈、分析结果/修复、Simulink自身运行检查、工作区保存、PNG/FIG及持久图像功能继续保留。

## 手动唤起与启动动画

普通MATLAB桌面图标只启动MATLAB。安装器在用户startup.m中只注册程序搜索路径，不再调用matlabAI或Aileron，不打开助手或动画。已有旧联动块会迁移为单个路径注册块，保留其他用户代码并备份启动脚本；安装本身也不弹出助手。程序目录保留后，用户可在任意当前目录输入：

```matlab
Aileron
```

需要返回窗口句柄时可用app=Aileron。旧命令matlabAI仍可手动使用。已有助手再次唤起只聚焦原窗口，不重复创建或播放动画。关闭助手后再次手动打开才重新播放。Start-Windows.cmd是明确主动启动助手的入口；setupMatlabAI/Install-Windows.cmd仅注册命令，不自动启动。

动画默认启用，包含仙人掌Logo、蓝白柔光和品牌文字。收到真实就绪通知且品牌完整出现后，至少停留约3秒，再用约0.6秒淡出；加载快也不会立即结束。减少动态效果模式同样保留约3秒静态停留。展示由浏览器异步完成，不用pause阻塞MATLAB。Esc或关闭浮层可主动跳过。

工作区菜单“启动动画”可开关。未就绪浮层12秒兜底关闭，收到就绪后采用8秒完成保护；资源失败不阻止助手，构造失败清理窗口与计时器。后台运行不会自动打开助手或动画。不替换MATLAB原生启动画面。

保留Aileron.m、startup-animation.html和完整+matlabai文件夹。移动程序位置或更新旧安装时重新运行setupMatlabAI刷新路径；本机升级会直接迁移已有启动脚本。保存工作并重启MATLAB后使用新行为。
